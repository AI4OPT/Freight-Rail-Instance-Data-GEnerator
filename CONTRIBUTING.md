# Contributing Guidelines

Thanks for your interest in contributing to this project!

At this time, we are not accepting pull requests. However, we welcome contributions in the form of bug reports and feature suggestions.

## Bug Reports

If you experience an issue with our software, please [create an issue](https://github.com/AI4OPT/Freight-Rail-Instance-Data-GEnerator/issues/new?labels=bug&type=bug). Please describe the problem in detail, including steps to reproduce the bug, and any relevant information such as error messages or screenshots. This will help us identify and fix the problem more quickly.

> [!IMPORTANT]
> If you are reporting a security vulnerability, please do not create a public issue. Instead, follow the instructions in our [Security Policy](SECURITY.md) to report the vulnerability privately.

## Feature Suggestions

If you have a suggestion for a feature or improvement to existing functionality feel free to can create [create an issue](https://github.com/AI4OPT/Freight-Rail-Instance-Data-GEnerator/issues/new) describing your idea. Please explain the problem it solves, how it would work, and any potential challenges or considerations. While we cannot guarantee a timeline for implementing feedbacks received, we value your input and will review suggestions carefully.
